Spécifications techniques

Processeur & Système d'exploitation

• Redmi Note 8 (2021)

   • Processeur : MediaTek Helio G85 Octa-core

   • Processeur graphique (GPU) : Mali-G52 MP2

   • Système d’exploitation initial : Android 11 avec MIUI 12.5

• Redmi Note 8T

   • Processeur : Qualcomm Snapdragon 665 Octa-core

   • Processeur graphique (GPU) : Adreno 610

   • Système d’exploitation initial : Android 9 avec MIUI 10

• Redmi Note 8 Pro

   • Processeur : MediaTek Helio G90T Octa-core

   • Processeur graphique (GPU) : Mali-G76 MC4

   • Système d’exploitation initial : Android 9 avec MIUI 10

Caméras & Résolution vidéo

• Redmi Note 8 (2021)

   • Caméra arrière : quadruple 48 MP + 8 MP + 2 MP + 2 MP

   • Résolution vidéo : 1080p@30fps

   • Caméra frontale : simple 13 MP

   • Résolution vidéo : 1080p@30fps

• Redmi Note 8T

   • Caméra arrière : quadruple 48 MP + 8 MP + 2 MP + 2 MP

   • Résolution vidéo : 4K@30fps, 1080p@30/60fps

   • Caméra frontale : simple 13 MP

   • Résolution vidéo : 1080p@30fps

• Redmi Note 8 Pro

   • Caméra arrière : quadruple 64 MP + 8 MP + 2 MP + 2 MP

   • Résolution vidéo : 4K@30fps, 1080p@30/60fps

   • Caméra frontale : simple 20 MP

   • Résolution vidéo : 1080p@30fps

Stockage & RAM

• Redmi Note 8 (2021)

   • RAM : 4 Go

   • Stockage : 64 Go, 128 Go

• Redmi Note 8T

   • RAM : 3 Go, 4 Go

   • Stockage : 32 Go, 64 Go, 128 Go

• Redmi Note 8 Pro

   • RAM : 6 Go

   • Stockage : 64 Go, 128 Go

Écran & Résolution

   • Résolution : 1080 x 2340 pixels (FHD+)

   • Protection : Corning Gorilla Glass 5

• Redmi Note 8T

   • Écran : IPS LCD, 6.3"

   • Résolution : 1080 x 2340 pixels (FHD+)

   • Protection : Corning Gorilla Glass 5

• Redmi Note 8 Pro

   • Écran : IPS LCD, 6.53"

   • Résolution : 1080 x 2340 pixels (FHD+)

   • Protection : Corning Gorilla Glass 5

Batterie & Type de charge

• Redmi Note 8 (2021)

   • Batterie : 4000 mAh (Li‑Po)

   • Type de charge : Charge rapide 18 W

• Redmi Note 8T

   • Batterie : 4000 mAh (Li‑Po)

   • Type de charge : Charge rapide 18 W

• Redmi Note 8 Pro

   • Batterie : 4500 mAh (Li‑Po)

   • Type de charge : Charge rapide 18 W

Cartes SIM & Carte microSD

• Redmi Note 8 (2021)

   • Cartes SIM : Dual Nano-SIM

   • Carte microSD : emplacement dédié, jusqu’à 256 Go

• Redmi Note 8T

   • Cartes SIM : Dual Nano-SIM

   • Carte microSD : emplacement dédié, jusqu’à 256 Go

• Redmi Note 8 Pro

   • Cartes SIM : Dual Nano-SIM (hybride)

   • Carte microSD : emplacement hybride (microSD ou Nano-SIM), jusqu’à 256 Go

Audio

Évaluation

Redmi Note 8 (2021)

• Points positifs

   + Mise à jour technique pertinente pour le segment budget, avec un SoC Helio G85 plus récent

   + Même formule éprouvée que Redmi Note 8 original

   + Compatible microSD, écran FHD+ et lecteur d’empreintes

• Points négatifs

   - Des tests le jugent peu innovant (édition “plutôt banale”)

   - Performances photo moyennes par rapport à la concurrence

   - Pas de grandes améliorations significatives vs modèle précédent

• Note globale

⭐ 4 / 10 ⭐

• Conclusion

Smartphone correct pour un usage basique (messages, applications, photos occasionnelles), adapté à un budget très serré
Redmi Note 8T

• Points positifs

   + Design moderne pour la catégorie

   + Ajout de NFC pour paiements mobiles / titres de transport

   + Écran IPS lumineux, lisible même en plein soleil

   + Excellent rapport qualité‑prix

• Points négatifs

   - MIUI peut afficher des publicités dans le système

   - Qualité photo globale correcte mais pas exceptionnelle

   - Chargeur et autonomie jugés moyens dans certains tests

• Note globale

⭐ 8,5 / 10 ⭐

• Conclusion

Smartphone complet sans trop dépenser, avec NFC, bonnes performances générales et autonomie correcte
Redmi Note 8 Pro

• Points positifs

   + Très bonne performance générale, adaptée aux jeux et multitâche

   + Écran lumineux et contrasté pour un smartphone milieu de gamme

   + Caméra principale 64 MP plus performante et utile, avec options vidéo intéressantes

   + Bonne autonomie grâce à la batterie 4500 mAh

• Points négatifs

   - Module photo proéminent peut gêner à plat

   - Macro peu utile selon certains tests

   - Recharge rapide limitée à 18 W (pas très rapide pour certains utilisateurs)

• Note globale

⭐ 9,0 / 10 ⭐

• Conclusion

Smartphone à performances élevées, bon jeu mobile, un appareil photo plus performant et une meilleure autonomie dans une tranche de prix abordable
Principales différences entre les modèles

   • Performance (processeur)

   • Qualité de la photo principale

   • Écran

   • Batterie

   • NFC
