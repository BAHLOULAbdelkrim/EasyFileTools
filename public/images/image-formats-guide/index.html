Image Formats (Guide)

Compare raster and vector image formats by compression, transparency, animation, compatibility and typical use. The best format depends on whether you need photographic quality, lossless graphics, transparency, very small web files or editable vectors.

Quick Choice

Choose a format quickly

Photos & broad compatibility JPG
Screenshots, UI & lossless graphics PNG
Modern web images WebP / AVIF
Transparency PNG / WebP / AVIF
Simple animation GIF / WebP
Logos & scalable graphics SVG
Scanning / print archive TIFF
Conversion is not always neutral Converting a lossy image such as JPG to another lossy format can introduce another generation of compression. Converting to PNG does not restore detail already lost in the source. Keep the original file whenever long-term quality matters.

JPG / JPEG

Universal

Lossy raster format optimized for photographs and continuous-tone images. It offers excellent compatibility and usually small files, but it does not preserve transparency.

High efficiency
