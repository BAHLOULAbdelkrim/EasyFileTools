How to resize or crop an image

  1. Select an image and choose the resize or crop controls.
  2. Set dimensions or a crop ratio and review the position.
  3. Apply the change and download the image.

Example use cases

  • Crop a photo to a square profile image.

Limitations to consider

  • Upscaling does not recreate missing original detail.

Questions and practical tips

What is the difference between resizing and cropping?

Resizing changes pixel dimensions. Cropping removes part of the image to change its framing. Keep the aspect ratio when resizing to avoid stretching the subject.

Will enlarging an image add real detail?

No. Enlarging creates more pixels but cannot recover missing detail. Enable the option that prevents enlargement when you only want to reduce images.

Processing and file safety

This tool processes files in your browser. Loading the page, libraries or AI models can still require network connections. Keep a copy of your original files and check the downloaded result before deleting them. Large files may require more memory and processing time than your device can provide.
