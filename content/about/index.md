## Tools for everyday file tasks

EasyFile Tools brings together browser-based operations for audio, video, images and PDF documents. Start with the [available tools on the homepage](/), select a file and review the settings before processing. Features labelled “Coming soon” are not yet available.

## Browser-based processing

The available file-processing tools run on your device. Pages can also load fonts, libraries and processing models from external services. Local processing therefore does not mean that visiting the site makes no network requests.

The file-selection workflow can retain files in browser storage while you navigate between tools. Use the file-removal controls when you are finished; clearing this site's data in your browser also removes its stored data. Avoid leaving sensitive files in a shared browser profile.

## Check the result

Keep the original file until you have opened and checked the downloaded result. Compression, conversion and image-based PDF processing can change quality or remove features. Available formats and practical limits depend on the operation, browser and device.

## Choosing a tool

Explore [audio tools](/audio/), [video tools](/video/), [image tools](/images/) or [PDF tools](/documents/). Each category also includes a guide comparing common file formats.
